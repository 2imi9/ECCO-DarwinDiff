% readme_components.tex -- README Figure 2, the "differentiable table", without math.
%
% What it shows: every component of the flagship DarwinDiff training step, one row each, in an
% ML-paper (booktabs) method table. The columns say whether a component is LEARNED, whether it is
% DIFFERENTIABLE (sits on the gradient path), whether it varies PER CELL or is shared, and where it
% comes from. Exactly one row is learned (the per-cell 1x1-conv network, set in bold on an opaque
% ddWash band: the "ours highlighted" idiom); theta is its bounded output. The model group runs in
% data-flow order: network -> bounds map -> theta -> box step, then the fixed constants. Under the
% bottom rule sits the key to the table's glyphs (a booktabs table note).
%
% The table carries no equations: its old Form column (each row's term in symbols) and its footer
% definitions (5) Z, (6) E, (7) rho moved, unchanged, to readme_equations, with the loss rows'
% Forms written there as the one sum L_a. Every equation keeps its one README number. Here each
% row whose math lives in readme_equations ends its label with a small ddMute tag: (1) theta and
% SST, (2) the box step, the forcing and the initial state (phi_c and x_{c,0} = x_c^IC are (2)'s
% inputs), (5) / (6) / (7) on the loss rows (the equation that defines the row's symbol, as the
% old Form column tagged them). (3) stays on the loss group tag ('loss on x_T (3)', which also
% says every loss row reads the END state) and (4) on the key's red tick ("on the gradient
% path"). The only math left is in labels: theta, phi_c and x_T, the diagram's own symbols.
%
% Verified facts behind the rows (the equations' code references are in readme_equations'
% header). "runner" = scripts/run_v3.0_joint_multi_aoi.py; config = scripts/configs/flagship_geo1.sh.
%   network, bounds map, theta, SST: a LINEAR bounds map for all six parameters (PARAM_LOG_SCALE
%     unset); the SST z-score pools the ocean cells of all three regions.
%     src/darwindiff/carroll6.py:621-679; src/darwindiff/networks.py:112-135 (three 1x1 convs =
%     one per-cell MLP f_w, shared weights w); runner :1837-1851, :1886-1887, :2550.
%   box step: forward Euler, theta constant in t. src/darwindiff/carroll6_5pft_2layer.py:383-636;
%     runner :2025-2044 (_integrate).
%   inputs (verified by executing the flagship code): the NETWORK reads SST alone
%     (n_input_channels=1). The BOX reads the forcing phi_c at every step: the v05 time means
%     SST_c (the SAME field as z_c's), SSS_c, wind speed_c and atmospheric pCO2_c (runner
%     :913-930, passed to every step at :2245-2250 via _integrate :2025-2044; SST also sets the
%     Eppley factor; v05 MLD is not used by the box). It starts from x_{c,0} = x_c^IC: the 10
%     chemistry tracers (Fe, POC, PIC, DIC, ALK, both layers) from the v05 pickup (DARWIN_IC=1,
%     runner :1720-1739, build_darwin_ic_cache.py), the 5 plankton from literature constants
%     (:1694-1702). Neither is learned or on the gradient path (w is the only optimised quantity).
%     Network inputs tried and dropped (wind, SSS, pCO2, CO2 flux, MLD):
%     docs/findings/2026-07-22_covariate_channels_result.md.
%   loss, on the END state x_T: the six loss rows are the summands of L_a (runner :2243-2519,
%     aoi_loss; state_final :2256; region weights :2562). The observation terms exist only in
%     regions with observed cells (runner :2450, :2465).
%   iron-budget residual: a SIMPLIFIED surface-Fe balance (no temperature factor, no diffusion),
%     not the box's own Fe balance: runner :2289-2308 against carroll6_5pft_2layer.py:530-535.
%     One name for it throughout: the row's Source and (7)'s heading in readme_equations both say
%     "surface iron balance".
%   comparison to Carroll: after training, under no_grad, outside the objective: runner :2698-2735.
%
% Canvas: 499 x 326 bp (176.04 x 115.00 mm). pdftocairo fits a page whose size is not a whole
% number of bp onto a whole-bp page, shrinking the SVG and leaving an unpainted sliver at its edges;
% a whole-bp page gives the SVG an identity transform, so the committed SVG matches the PDF. The
% page was 453 bp with the footer; everything is drawn in the old coordinates and lowered by the
% 127 bp the footer took, which leaves 4.7 mm of white under the key, matching the 4.85 mm over
% the top rule.
%
% Rules it follows (dd-readme.sty):
%   * red = the gradient: here ONLY the thin check strokes; never a fill or a text colour. The
%     tags and sub-labels are ddMute.
%   * blue bar = a real observation; gold bar = ECCO-Darwin v05 model output. Full strength.
%   * "Differentiable" is defined on components and loss TERMS, never on data.
%   * booktabs look: no vertical rules, no zebra, no row outlines, no shadows, no opacity; the
%     only shading is the one learned-row band, drawn before the rules. Top, mid and bottom rules
%     span x 1.5-174.5 so the rotated group tags sit inside the frame (a multirow group column);
%     the group separators are partial, from x 7. Every cell sits on the column grid.
%   * no result numbers: the numerals are "1x1", the citation years, the equation tags, the
%     product name "ECCO-Darwin v05" and the 2 of CO2 and pCO2. No weights, parameter values,
%     tracer or step counts (the inputs say "chemistry + plankton", not 10 + 5).
%   * the Per cell column is one glyph family, a 3x3 hairline grid (ddMute stroke): light grey
%     texture = varies by cell, one uniform grey = one shared value, two ink cells = sparse
%     observations (all three keyed in the legend).
%   * 8 pt floor, drawn at final size (176 mm = the README column), opaque white canvas. The math
%     inside the 8 pt sub-labels and tags keeps its scripts at 8 pt (\DeclareMathSizes{8}{8}{8}{8}),
%     where LaTeX would drop them to 6 and 5 pt; theta and phi_c are slanted Euler, as in
%     readme_method and readme_equations (pdffonts: NimbusSans, EURM only).
%
% Deviations from the plan spec (round-1 review, the math passes, then the math moved out):
%   - no Form column (it moved to readme_equations). The four remaining columns are re-spaced
%     across the 176 mm: the Component column runs to x ~79 (the longest label, 'other network
%     inputs' and its list of dropped inputs, ends at 78.9), the glyph columns are centred at 84 /
%     106.5 / 129 and Source starts at 145.5, so the header gutters are 8-12 mm and the longest
%     Sources end ~1.8 mm inside the rules. Headers at 8 pt bold.
%   - the old Form column's words became sub-labels, so no content was lost with the math: the
%     forcing row's list ('SST, SSS, wind, pCO2 time means', was 'box input, time means' beside
%     the Form 'phi_c: SST, SSS, wind, pCO2'), the dropped network inputs' list, and the scope
%     rows' 'not in the box step' (was the Form 'not in F') and 'after training, not in the loss'
%     (was 'after training, not in L'). The 'L_a =' and '+' column ahead of the loss Forms went
%     with them (L_a is written out in readme_equations).
%   - no type-glyph column (the v2 shape-grammar squares): at README width it read as a column of
%     unchecked checkboxes, it had no key, and the Learned dot/ring and the gold/blue bars already
%     carry learned vs data vs source.
%   - no dashed outlines on the two scope rows: the scope group is marked by its tag, its separator
%     and italic ddMute names, like any other booktabs group.
%   - the lateral-transport row sits on the column grid: dashes in Learned, Differentiable and Per
%     cell, and a Source note that says what is absent, "no cell-to-cell exchange", since cells ARE
%     coupled through the shared weights and the per-region z-scoring of the pattern term.
%   - the glyph columns are snapped to the 200 dpi pixel grid (see \ddrow). Rows are 5.2 mm apart
%     (was 4.6) so superscripts and subscripts clear.
%   - the pattern term is two rows: "pattern term" (the 11 base fields) and "extra pattern terms"
%     (the POC_2 and Chl_1 z-terms: the same shape-only Z, with their own weights).
%   - short Sources: "v05 pickup + literature" (the gold bar and the legend name ECCO-Darwin) and
%     "surface iron balance", with "simplified" in the residual's sub-label. Sub-labels: "1x1
%     conv" (the Per cell glyph says shared), "forward Euler", "dust, Fe:C quota", "both layers".
%   - the inputs group is four rows: SST, sub-labelled "only network input, in phi_c too" (the
%     network reads SST alone; the same field is also box forcing); "forcing"; "initial state"
%     (chemistry + plankton), Source "v05 pickup + literature" in the same order as its sub-label,
%     its bar gold on top (the v05 part) and the fixed grey below (the literature constants); and
%     the network inputs tried and dropped, set like the scope rows (italic ddMute, dashes). The
%     forcing row sits 1 px (0.127 mm) above the 5.2 mm pitch: on it, its dashes fell on a pixel
%     boundary at 880 px and printed twice as thick as the rest of the column.
%   - theta's source is "network + bounds map": theta here, as in readme_method, is the bounded
%     parameter field that enters the box.
%   - the learned dot is 2.6 mm (spec 2.2) so the one learned mark is the darkest in its column.
%   - the GRID greys are white/C8/7F (spec ED/D9/C4) so "varies by cell" reads as a checkered
%     texture at README width, clearly apart from the flat grey of SHARED; SHARED is the same grid
%     filled uniformly (spec: a 1.6 mm ddMute square).
%   - the legend drops the learned dot (its column header says it) but keys the red check as
%     "on the gradient path (4)", the one place readme_method's (4) is anchored here; it is
%     centred on the rule span and sits directly under the bottom rule as a table note.
%   - the learned row's source is "trained here" (spec "this repo"); both scope rows set their
%     Source in italic ddMute, like their names.
