% in data-flow order: network -> bounds map -> theta -> box step, then the fixed constants. The
% loss rows are the summands of L_a: 'L_a =' ahead of the first and a ddMute + ahead of the rest,
% so the Form column reads as one equation. Under the bottom rule sits the key to the table's
% glyphs (a booktabs table note), then a footer with the three equations the loss rows use.
%

% theta and SST Forms, (2) after the box step's, the forcing's and the initial state's (phi_c and
% x_{c,0} = x_c^IC are (2)'s inputs), (3) on the loss group tag ('loss on x_T (3)',
% which also says every loss row reads the END state; the loss rows' 'L_a =' is (3)'s L_a), (4)
% on the key's red tick ("on the gradient path"), and (5), (6), (7) after each Form that uses the
% symbol. The footer heads each block '(n) name' as readme_method's equation band does (number
% ink, name ddMute), with the equation flush left under the heading and at most two lines of
% readme_method-style symbol key ('symbol meaning . symbol meaning') under it.

%     src/darwindiff/carroll6_5pft_2layer.py:383-636 (Euler :610-626, clamp :636); runner
%     :2025-2044 (_integrate).
%   inputs (verified by executing the flagship code): the NETWORK reads SST alone
%     (n_input_channels=1; z_c above). The BOX reads the forcing phi_c at every step: the v05
%     time means SST_c (the SAME field as z_c's), SSS_c, wind speed_c and atmospheric pCO2_c
