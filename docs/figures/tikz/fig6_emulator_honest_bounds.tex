% WHY THIS FIGURE EXISTS

% every scale tested" bar chart, which is the +0.408 run with surfChl4 at -606.93 simply left out.
% This replaces both. Every number here is measured, sourced, and survives the correction.
%
% SEMANTICS OF THE THREE-COLOUR LADDER IN THIS FIGURE
% darwindiff-tikz-v2.sty fixes the palette to a luminance ladder with exactly three rungs and
% assigns them meanings for the PARAMETER figures. This is not a parameter figure, so the mapping
% is restated rather than assumed, and it is used consistently in all four panels:
%
%   ddBlue  the honest measurement -- log space, the space the quantity is defined in
%   ddGold  the superseded measurement -- linear space, which is what produced +0.408
%   ddRed   STROKE ONLY, and it never means "bad": it marks output that is NON-PHYSICAL,
%           a property no skill score can see
%
% SOURCES, all in docs/findings/
%   2026-07-30_daily_emulator_rescored_vs_ar1.md   panels a, b, c   jobs 236516 / 236529
%   2026-07-30_daily_logspace_training.md          panel d          jobs 237761/237762/237763
%
% surfChl4 IS SHOWN. It is the channel the retracted chart omitted, and omitting it is what made
% the average look positive. Its linear skill of -606.11 is a division by noise: 100% of its truth
% values are non-positive, so log space is undefined for it and it should never be a target again.
