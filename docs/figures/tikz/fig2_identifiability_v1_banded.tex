% fig2_identifiability_v1_banded.tex -- IDENTIFIABILITY MAP, variant 1: "banded verdict map".
%
% Design intent. The paper's ethic is that "unobservable by construction" is an EXCLUSION,
% not a failure. Encoding it as a low score on the same axis as the recovered parameters
% would misreport the science. So the map is BANDED: three bands with their own left-hand
% rubric, and the excluded pair sits in a visually separate band with a neutral (not red)
% treatment and an explicit disclaimer. Verdict is carried by fill tint + border + a written
% word, never by hue alone, so the figure survives greyscale.
%
% Every number here is verify_run-gated and re-derived from the raw per-seed records of the
% flagship run n50e2k_percell_trio (n=50, 2000 epochs), plus its epoch-matched controls.
