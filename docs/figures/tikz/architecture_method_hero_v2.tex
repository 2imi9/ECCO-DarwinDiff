% (node distance + right=of/below=of), NO manual (x,y) coordinates for layout. This fixes the

%   * cards use `text width` (not minimum width) so text wraps instead of clipping;
%   * every panel is a `fit` box on the background layer (auto-sized, no literal rectangle corners).
