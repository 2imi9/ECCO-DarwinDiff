# 3-D depth-resolved global emulator beats persistence (2026-07-14)

The emulator was surface-only. This extends it to a **depth-resolved** global-monthly emulator —
the substantive upgrade, since ocean carbon is a 3-D system (surface pCO₂ is driven by *subsurface*
DIC). All numbers are **local** (self-consistency vs the v05 model output, not real observations).

## Result

- **Verdict: MAKE. Overall skill vs persistence +0.507 (linear space)** (mean per-channel +0.396, linear space).
  - Metric space matters: global Chl is log-normal (p99/p1 = 2.8e6x), so linear-space skill is dominated by a few bloom cells. A log-space control on the comparable monthly 3-D configuration retains most of the skill (+0.432 linear -> +0.365 log, -15%); the equivalent log-space control for *this* 60-channel run has not been run.
- **Grid:** global 0.25° (680×1440), **10 depth levels** (upper ~150 m), 6 tracers → **60 channels**.
- **Model:** FNO2d, modes 24, width 48, residual + rollout-k4 + `--rollout-positivity`, batch 2.
- Data: 302 GB of monthly 3-D tracer files downloaded B200-native to AICR; 18 GB extracted cube.

## Depth generalizes; the tracer pattern matches the surface

| Tracer group | Mean skill vs persistence, **linear space** (10 levels) |
|---|---|
| PIC / POC (particulate carbon) | **+0.535** |
| FeT / Chl1 (iron / chlorophyll) | +0.410 |
| DIC / ALK (carbonate) | +0.244 |

The particulate tracers are predicted best; the slow carbonate tracers (DIC/ALK) are hardest —
the **same ordering as the surface emulator**, now holding through the water column. Overall skill
(+0.507, linear-space skill vs persistence, single seed) is slightly below the global monthly *surface* run (+0.5204 linear, seed 0; +0.5165 ± 0.0023 over n=5) — a separate run, and the 3-D side is one seed, so read the gap as indicative rather than resolved: predicting the full 60-channel column
is harder than the surface alone, but the method generalizes to depth without modification.

## Significance

This is the one genuinely different problem the overnight loop pursued (every input/rollout *tweak*
was rejected — see `2026-07-14_emulator_loop.md`). A depth-resolved emulator that beats persistence (persistence only — no climatology baseline was run for this configuration, so the significance of +0.507 is not yet established against the harder reference; in the separate rollout-horizon experiment persistence still reads a "strong" +0.441 at 12 months where climatology reads −0.265, i.e. persistence can mask rollout drift)
across the upper ocean is a step from a surface demo toward a usable ocean-carbon forward tool.

## Limitations

- Self-consistency vs the v05 model output; not validation against real observations (#163).
- Upper **10 levels (~150 m)** only, not the full 50-level column.
- **Single seed — and single seed is not the ceiling.** On a comparable (but distinct) monthly 3-D run, an 8-seed deep ensemble lifts skill +0.432 → +0.484; EDM diffusion adds no skill and *hurts* on 3-D (+0.421 → +0.395). The +0.507 above is one seed of this run and should be read as a floor, not a limit. (Capacity is separately known *not* to be the lever: ~4× parameters bought +0.007. Ensembling is the lever.)
- **Physical validity is not verified for this run, and the skill score cannot detect it.** All skill numbers here are **linear-space** skill-vs-persistence, which is blind to physics: a monthly 3-D emulator in this family scores +0.43 while inventing **4.5% negative iron cells** where v05 emits 0.0%. `--rollout-positivity` is a partial mitigation, not a guarantee — on eqpac it took negatives 0.182 → 0.083 (not to zero) and left multi-step mean drift unfixed (see `2026-07-14_emulator_loop.md`). Log-space training removes negatives by construction; this run is linear-space, so a negatives-and-conservation check is required before these fields are used for anything downstream.
- Overall skill is a channel aggregate; a proper **per-depth-level** profile (does skill decay with
  depth?) is the natural next diagnostic — the channels are named `Tracer_kLevel` so it is a
  regrouping of the existing run.
